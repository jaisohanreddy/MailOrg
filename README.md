# MailOrg

> AI-powered workspace that learns what deserves your attention, starting with email.

---

## 🚀 Vision

MailOrg helps people focus on what matters by understanding their priorities and intelligently organizing their communication.

---

## 📌 Current Status

🚧 This project is currently in active development.

We are building the MVP step by step.

---

## 🎯 Goals

- Connect with Gmail
- Learn user priorities
- Classify emails using AI
- Explain every AI decision
- Continuously improve through feedback

---

## 🛠 Tech Stack (Planned)

- Next.js
- TypeScript
- Tailwind CSS
- Auth.js
- Prisma
- PostgreSQL
- OpenAI API
- Gmail API
